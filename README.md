# LM Labeling Tool

**한국어** | [English](README.en.md) | [中文](README.zh-CN.md)

AI 서버가 만든 스티칭 이미지와 균열 마스크를 **내 PC에서 직접 보정**하는 라벨링 도구입니다.
균열 마스크 편집, 보수 구역(OBB) 표시, 축척(px/cm) 확인을 마친 뒤 결과를 서버(EC2)로 다시 업로드합니다.

작업 흐름: **로그인 → 데이터 가져오기 → 라벨링 → EC2 업로드**

---

## 다운로드

[**최신 버전 다운로드 (Releases)**](https://github.com/CYHooo/labeling-tool/releases/latest) — 페이지 맨 위 표에서 내 운영체제의 파일 **하나만** 받으면 됩니다.

| 운영체제 | 받을 파일 | 크기 |
|---|---|---|
| Windows 10 / 11 (64-bit) | `LM_LabelingTool-Setup-v<버전>.exe` | 약 1.6 GB |
| Ubuntu 22.04 / 24.04 (64-bit) | `lm-labeling-tool_<버전>_amd64.deb` | 약 1.8 GB |

## 설치

### Windows

1. 받은 `LM_LabelingTool-Setup-v<버전>.exe` 를 더블클릭합니다.
2. "Windows의 PC 보호" 창이 뜨면 **「추가 정보」 → 「실행」** 을 누릅니다.
3. 설치 마법사를 기본값으로 진행합니다. 관리자 권한은 필요 없습니다.
4. **시작 메뉴**에서 **LM_LabelingTool** 을 실행합니다.

### Ubuntu

```bash
sudo dpkg -i lm-labeling-tool_<버전>_amd64.deb
```

애플리케이션 메뉴에서 **LM Labeling Tool** 을 실행합니다.

## 업데이트

프로그램이 **시작할 때와 실행 중 4시간마다** 새 버전을 확인합니다. 직접 확인하려면 로그인 화면의 「업데이트 확인」을 누르세요.

- 작은 업데이트(몇 MB)는 백그라운드에서 미리 받아 두었다가 알려 줍니다. 「지금 재시작하여 업데이트」를 누르면 바로 적용됩니다. Ubuntu에서는 비밀번호를 한 번 입력합니다.
- 라벨링 중에는 작업을 방해하지 않고, 작업 창을 닫을 때 알려 줍니다.
- 전체 설치 파일이 필요한 큰 업데이트는 크기를 먼저 알려 주며, 동의하기 전에는 내려받지 않습니다.
- 업데이트 중 오류가 나거나 전원이 꺼져도 이전 버전으로 되돌아갑니다.

## 사용 방법

로그인 화면에는 탭이 두 개 있습니다.

| 탭 | 용도 |
|---|---|
| **라벨링** | 서버에서 새 작업을 가져오거나, 이 PC 에 받아 둔 작업을 이어서 라벨링하고 업로드합니다. |
| **Few-shot 라벨링** | SAM2.1 기반 다중 클래스 라벨링. 처음 열 때 모델(약 308 MB)을 한 번 내려받습니다. |

### 1. 로그인과 작업 열기

`BASE URL` 과 `X-Viewer-Api-Key` 를 입력합니다. 입력값은 저장되어 다음부터 자동으로 채워집니다. 그 아래 **로컬 작업** 목록에는 이 PC 에 받아 둔 작업이 최근 순으로 표시됩니다.

- **새 작업**: 「새 작업 가져오기」 → 작업을 고르고 필요하면 `fromNum` / `toNum` 으로 사진 범위를 정합니다 (0 = 처음부터 / 끝까지) → 「가져오기 (다운로드)」. 사진을 받은 뒤 라벨링 화면이 열립니다.
- **받아 둔 작업**: 목록에서 골라 「열기」 (또는 더블클릭). 업로드는 그 작업을 받은 서버로 가며, Key 를 비워 두면 이 PC 에만 저장됩니다.
- 이미 받은 작업을 다시 가져오려고 하면 「열기」 / 「다시 가져오기」 를 묻습니다. 다시 가져와도 라벨링 결과와 업로드 기록은 유지됩니다. 다른 서버에서 받은 같은 번호의 작업은 여기서 열 수 없습니다.

### 2. 라벨링

| 기능 | 설명 |
|---|---|
| **브러시** | 균열을 대략 그리면 손을 떼는 순간 1px 중심선으로 정리됩니다. 실제 폭을 남기려면 「정밀 라벨링 (굵기 유지)」를 켭니다. |
| **보수 구역** | 회전 가능한 사각형(OBB)으로 보수 영역을 표시합니다. 겹친 면적은 한 번만 계산됩니다. |
| **축척 (px/cm)** | 서버가 계산한 값을 그대로 씁니다. 고치려면 「수동 측정 (대체)」으로 기준선 두 점과 실제 길이를 입력합니다. |
| **SAM 분할 (박리)** | 좌클릭(포함)·우클릭(제외)으로 박리 영역을 자동으로 잡고 「확정 (박리 기록)」으로 기록합니다. Esc 는 마지막 점을 취소합니다. |
| **하이라이트 표시 / 15cm 경계 표시** | 균열 주변 하이라이트와 보수 구역 15cm 경계를 미리 봅니다. |

이미지를 넘기면 자동 저장되며, 「마스크 저장」으로 직접 저장할 수도 있습니다.

### 3. EC2 업로드

「EC2 업로드」를 누르면 **수정한 사진만** 마스크 · 하이라이트 · 15cm 경계를 함께 업로드합니다. 업로드 후 서버에 반영되었는지 다시 확인하며, 실패한 사진은 번호와 함께 알려 줍니다. 자세한 기록은 작업 폴더의 `vapi.log` 에 남습니다.

## 언어 설정

화면 언어(한국어 / 中文 / English)는 로그인 화면 아래쪽 또는 라벨링 화면의 「설정」에 있는 「언어:」에서 바꿉니다. 선택한 언어는 저장됩니다.

## 데이터 위치와 제거

| | 데이터 위치 | 제거 방법 |
|---|---|---|
| Windows | `%LOCALAPPDATA%\Programs\LM_LabelingTool` | 제어판 → 프로그램 제거 |
| Ubuntu | `~/.local/share/lm-labeling-tool/` | `sudo apt purge lm-labeling-tool` |

설정, 받은 작업, 모델 파일은 **제거해도 남아 있으므로** 다시 설치하면 그대로 이어서 쓸 수 있습니다.
